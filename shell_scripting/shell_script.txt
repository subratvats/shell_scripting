${var#pattern} → shortest match from beginning
${var##pattern} -> It removes the longest matching pattern from the beginning (left side)

${var%pattern} → shortest match from end
${var%%pattern} → longest match from end

${var/pat/repl}      replace first match
${var//pat/repl}     replace all matches
var="hello world world"

echo "${var/world/Bash}"  ===hello Bash world
echo "${var//world/Bash}"  ===hello Bash Bash

Syntax		Meaning	Example
${VAR,,}	Convert to lowercase	HELLO → hello
${VAR^^}	Convert to uppercase	hello → HELLO

Every normal Linux process has three standard file descriptors:
0 → stdin   → input
1 → stdout  → normal output
2 → stderr  → error output

command > output.log
command 1> output.log

command 2> error.log

command &> output.log ~===~ command > output.log 2>&1

Send file descriptor 2 (stderr) to wherever file descriptor 1 (stdout) is currently going.
command > /dev/null 2>&1  # silenced everything

🚀 Level 8 — grep + awk: Extracting Fields Like a DevOps Engineer
awk is a powerful text-processing command in Linux used to analyze, filter, and manipulate structured data such as logs, CSV files, and command output. It works by scanning input line by line and performing actions based on patterns and fields.

grep is excellent for finding patterns.
awk is excellent for working with columns/fields.
awk [options] 'pattern {action}' input-file

10.20.30.40 GET /api/users 200
10.20.30.41 POST /api/login 500
192.168.1.25 GET /api/orders 404

$1             $2       $3          $4
│              │        │           │
IP             Method   Endpoint    Status

awk -F' ' '{print $1}' access.log
NOTE default seperator is spaces/tabs

$0 → entire line
$1 → first field
$2 → second field
$3 → third field
...

NF — number of fields

awk '{print NF}' access.log

awk '{print $NF}' access.log  == last field This is extremely useful when the number of fields can vary.

NR — line number Number of the current record/line

awk '{print NR, $0}' access.log
1 10.20.30.40 GET /api/users 200
2 10.20.30.41 POST /api/login 500
3 192.168.1.25 GET /api/orders 404
4 192.168.1.25 GET /api/orders 404
5 192.168.1.25 GET /api/orders 404

Filtering with awk

awk '$4 == 500' access.log  => Find only lines where status is 500:

awk '$4 == 500 {print $1}' access.log  ==> Print only the IP for 500 errors

grep 'POST' access.log | awk '$4 >= 400 {print $1, $3, $4}'  ==> Combining grep and awk
awk '$2 == "POST" && $4 >= 400 {print $1, $3, $4}' access.log  == above equivalent

awk '$2 == "POST" && $4 >= 400' access.log
awk '$2 == "POST" || $4 >= 400' access.log

🚀 Level 10 — Advanced awk: Variables, Calculations & Reports

BEGIN

BEGIN runs before awk starts reading the file.

awk 'BEGIN {print "Starting log analysis"}' access.log

END

END runs after all lines have been processed.
awk 'END {print "Finished"}' access.log


awk '{count++} END {print count}' access.log
awk '$4 >= 400 {errors++} END {print errors}' access.log

Calculate percentage

awk '
{
    total++
    if ($4 >= 400)
        errors++
}
END {
    print "Total:", total
    print "Errors:", errors
    print "Error %:", (errors / total) * 100
}' access.log

BEGIN + END for reports
----------------------

awk '
BEGIN {
    print "===== HTTP REPORT ====="
}
{
    total++

    if ($4 >= 400)
        errors++

    if ($4 >= 500)
        server_errors++
}
END {
    print "Total Requests :", total
    print "4xx/5xx Errors  :", errors
    print "5xx Errors      :", server_errors
    printf "Error Rate      : %.2f%%\n", (errors/total)*100
    print "======================="
}' access.log
